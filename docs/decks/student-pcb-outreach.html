The Project Cellular + SIM redesign

Our sensor board is a compact KiCad design built around an ESP32-H2. Today it needs a nearby gateway to reach the Internet. We want it to connect straight to a carrier network, so it works anywhere.
Today
Thread / BLE
Measures VOCs, temperature and humidity. Powered over USB-C. Needs an external gateway to get online.
Goal
LTE-M over SIM
Add a cellular modem (the Quectel BG95 family is one candidate), a SIM, and an antenna. The data path becomes SIM → carrier → Internet.
Outcome
A shipped board
You take a real design from schematic to a board we fabricate, bring up and use.
Where you start: the existing KiCad files and our browser-based board explorer, so you can inspect every part, pad and net before you change anything.

What You'd Work On

  1. 1
    Modem integrationKeep the ESP32-H2 as the sensor controller and connect an LTE-M modem over UART, with enable/reset lines. Check I/O voltages and add level shifting where needed.
  2. 2
    SIM + antennaAdd a SIM (or eSIM) holder, a cellular antenna and its matching/feed, and ESD protection.
  3. 3
    Power designAdd a dedicated modem rail (around 3.8 V, with transmit peaks near 1 A) and make sure the USB-C input budget holds up.
  4. 4
    Layout + reviewPlace and route the new parts in KiCad, run DRC, and get the board ready for fabrication.
  5. 5
    Bring-up Help test the first boards: power, SIM detection, network attach.
