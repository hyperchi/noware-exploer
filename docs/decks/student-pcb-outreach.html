The work

What you'd work on

  1. 01Modem integrationKeep the ESP32-H2 as the sensor controller and connect an LTE-M modem over UART, with enable/reset lines. Check I/O voltages and add level shifting where needed.
  2. 02SIM + antennaAdd a SIM (or eSIM) holder, a cellular antenna and its matching/feed, and ESD protection.
  3. 03Power designAdd a dedicated modem rail (around 3.8 V, with transmit peaks near 1 A) and make sure the USB-C input budget holds up.
  4. 04Layout + reviewPlace and route the new parts in KiCad, run DRC, and get the board ready for fabrication.
  5. 05Bring-upHelp test the first boards: power, SIM detection, network attach.
